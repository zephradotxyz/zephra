# Security policy

The contracts are unaudited. Please report vulnerabilities privately by email to **support@zephra.xyz** (subject: "Security"). Do not open a public issue for a vulnerability.

Include: what you found, how to reproduce it, and the affected contract or file. We will acknowledge your report and keep you updated until it is fixed.

Never commit private keys, API tokens or `.env` files. If you find a leaked credential in this repository, report it the same way.
